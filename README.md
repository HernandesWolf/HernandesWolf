## Sobre mim

Sou formado em Análise e Desenvolvimento de Sistemas e estou construindo meu portfólio com foco em desenvolvimento backend usando **Java, Spring Boot, APIs REST e bancos de dados relacionais**.

Gosto de transformar necessidades de negócio em soluções práticas, com atenção às regras de negócio, à integridade dos dados, à segurança e à manutenção do código. Neste perfil, documento meus projetos, decisões técnicas e evolução como desenvolvedor.

## Projetos em destaque

### [Flowdesk — Plataforma de gestão de chamados](https://github.com/HernandesWolf/Flowdesk_26)

Projeto voltado à organização de chamados e ordens de serviço, com foco em fluxo de atendimento e estrutura de API backend.

**Pontos técnicos documentados:** prevenção de vendas duplicadas, tratamento de concorrência, autenticação e testes.

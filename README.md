## Sobre mim

Sou formado em Análise e Desenvolvimento de Sistemas e direciono meus estudos e projetos para **desenvolvimento backend com Java, Spring Boot, APIs REST e bancos de dados relacionais**.

Tenho interesse especial em transformar necessidades de negócio em soluções confiáveis: regras de negócio explícitas, integridade dos dados, segurança, testes e código que possa ser mantido por outras pessoas.

Este GitHub reúne projetos práticos, documentação técnica e decisões de implementação. Procuro deixar claro o que cada projeto faz, como executá-lo e quais limitações ainda existem.

## Projetos em destaque

### [VagaRadar — Gestão de oportunidades e análise de aderência](https://github.com/HernandesWolf/VagaRadar_H1)

API REST para organizar candidaturas e comparar os requisitos das vagas com as competências cadastradas pelo usuário.

**Destaques técnicos:** análise determinística de lacunas (score de 0 a 100), pesos diferentes para requisitos obrigatórios e desejáveis, extração assistida de requisitos a partir do texto da vaga, máquina de estados para candidaturas, alertas e estatísticas.

**Tecnologias:** Java 17 · Spring Boot · PostgreSQL · H2 · Flyway · OpenAPI/Swagger · Docker · JUnit.

> A versão atual é voltada a uso individual e demonstração. Consulte o README para conhecer as limitações de segurança e o escopo implementado.

### [StockFlow — Gestão de estoque e vendas](https://github.com/HernandesWolf/StockFlow-H1)

API REST para gestão comercial, com foco na integridade das operações de estoque e vendas.

**Destaques técnicos:** controle de concorrência com bloqueio de linhas, idempotência para evitar vendas duplicadas, transações, trilha de auditoria, autenticação JWT e regras para impedir estoque negativo.

**Tecnologias:** Java 21 · Spring Boot · PostgreSQL · Spring Security · JPA · Flyway · Docker · Testcontainers.

### [FlowDesk — Gestão de chamados e ordens de serviço](https://github.com/HernandesWolf/Flowdesk_26)

Plataforma backend de service desk para empresas de manutenção, suporte e serviços em campo.

**Destaques técnicos:** arquitetura multi-tenant, fluxo de estados validado, controle de acesso por perfil, histórico de auditoria, alertas de SLA, notificações assíncronas e relatórios.

**Tecnologias:** Java 21 · Spring Boot · PostgreSQL · Spring Security · JWT · Flyway · Testcontainers · Docker.

### [Restaurante — Landing page](https://github.com/HernandesWolf/Restaurante-landing-page)

Projeto de interface web para apresentação de um negócio de restaurante.
